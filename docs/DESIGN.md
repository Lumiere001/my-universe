# 나의 우주 · 디자인 (옵시디언 느낌, 2026-10-22)

화면의 **모습**만 정한다. 화면에 보일 말은 `docs/content/`, 기능은 PRD v8 이 정한다. 코드는 `infra/frontend/app/globals.css`(색 · 글자 · 부품)와 `components/Shell.tsx`(틀)가 이 문서를 따른다.

## 1. 생각

나의 우주는 "AI가 연결을 대신 만들어 주는 일기용 옵시디언"이다. 옵시디언에서 노트가 왼쪽 목록에 쌓이고 그래프에서 이어지듯, 일기는 왼쪽 '지난 기록'에 쌓이고 우주에서 이어진다. 그래서 옵시디언의 **틀과 느낌**을 빌린다.

| 옵시디언 | 나의 우주 |
| --- | --- |
| 왼쪽 파일 목록(폴더 · 노트) · 달력 플러그인 | 사이드바 '지난 기록'(작은 달력 · 최근 기록 다섯 편) |
| 그래프 보기 | 우주 |
| 노트 위 속성(Properties) | 쓰기 화면의 글이 다루는 날 · 마음 날씨 |
| 백링크 | 결과 카드의 '이어진 지난 생각' |
| 콜아웃 | 별지기 말 |
| 태그 | 생각 종류 · 확신 · 가치 배지 |

빌리지 않는 것: 옵시디언 이름 · 로고 · 코드 · 그림. 옵시디언은 소스가 닫힌 앱이라 겉모습(배치 · 색의 느낌)만 참고하고 코드는 우리가 새로 쓴다. 아이콘은 Lucide(ISC 라이선스) 모양을 `components/Icon.tsx`에 옮겨 쓴다.

## 2. 틀

- **PC(900px 이상):** 왼쪽 사이드바(메뉴 7개 + 작은 달력 · 최근 기록) · 가운데 작업 칸(위에 '나의 우주 › 화면 이름' 머리줄). 사이드바는 머리줄의 단추로 접고 펼친다(이 기기에 기억).
- **휴대폰:** 위에 머리줄(메뉴 단추 · 화면 이름), 아래에 자주 쓰는 4개(이야기하기 · 쓰기 · 우주 · 지난 기록). 나머지 메뉴와 지난 기록 목록은 메뉴 단추로 여는 서랍에.
- 글 칸은 읽기 좋은 폭(760px)으로 가운데, 우주만 넓게.

## 3. 색 · 글자

어두운 회색 바탕에 보라 하나를 강조로 쓴다. 뜻이 있는 색은 그대로 둔다(보라 = 이어짐, 주황 = 맞섬 · 긴장, 금빛 = 다짐 · 북극성). 우주 안의 색은 꾸미기 테마(`universeLook.ts`)를 따른다.

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--bg` | #1e1e1e | 작업 칸 바탕 |
| `--bg2` | #262626 | 사이드바 · 머리줄 · 아래 막대 |
| `--panel` | #242424 | 카드 · 입력 칸 |
| `--hover` | #2f2f2f | 누를 수 있는 것에 마우스를 올렸을 때 |
| `--line` | #363636 | 나눔 선 · 테두리 |
| `--text` | #dadada | 본문 |
| `--muted` | #b3b3b3 | 보조 글 |
| `--faint` | #949494 | 더 흐린 글(목록의 날짜 등, 작은 글도 바탕 대비 4.5:1 이상) |
| `--accent` | #8b6cef | 강조 · 주 버튼 · 이어진 선 |
| `--accent-text` | #a882ff | 링크 · 강조 글자(어두운 바탕에서 읽히게 더 밝게) |
| `--orange` | #e8956f | 맞섬 · 긴장 · 지우기 |
| `--gold` | #e0bf62 | 다짐 · 북극성 |
| `--green` | #7cc79a | 잘됐어요 알림 |

- 글자: 기기 기본 글꼴(애플 SD 산돌고딕 Neo · Noto Sans KR). 본문 16px, 사이드바 · 배지 · 보조 글은 한 단계 작게.
- 모서리: 작은 것 6px, 카드 8px. 그림자는 서랍에만.

## 4. 부품

- **버튼:** 회색 바탕, 주 버튼만 보라. 손가락으로 누르는 기기에서는 높이 44px 이상.
- **배지:** 옵시디언 태그처럼 보라빛이 도는 알약. 주황 · 금빛은 뜻이 있을 때만.
- **별지기 말:** 콜아웃(보라 기운 바탕 + 왼쪽 굵은 선 + 별지기 이름 줄). 내 말은 강조 없는 회색 말풍선.
- **인용:** 왼쪽 선 하나 + 기울이지 않은 본문.
- **속성:** 쓰기 화면 제목 아래에 '이름 | 값' 줄들.
- **접는 칸(details):** 꺾쇠가 붙은 한 줄, 펼치면 안이 보인다.
- **우주의 카드:** PC는 오른쪽 사이드 칸, 휴대폰은 아래에서 올라오는 칸.
- **달력(지난 기록 · 사이드바):** 일요일부터 한 주. 기록이 있는 날은 보라 점(큰 달력은 세 편까지 점 수로), 오늘은 회색 테두리, 고른 날은 보라 바탕 + 보라 테두리. 사이드바는 같은 달력의 작은 판(옵시디언 달력 플러그인처럼). 지난 기록 화면은 한 화면에 들어가게 PC는 달력(또는 주제 목록) · 기록 목록 두 칸 나란히, 휴대폰은 위아래로 두고 목록만 안에서 넘긴다.

## 5. 하지 않은 것 (필요해지면)

- 밝은 모드: 우주가 어두운 바탕이라 지금은 어두운 모드 하나만.
- 명령 팔레트(⌘P) · 여러 탭 · 화면 나누기: 화면이 7개라 아직 필요 없음.
