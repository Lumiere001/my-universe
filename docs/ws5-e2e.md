## 보인 점(원문 없이)

- 4편 모두 진행 순서 · 결과 모양이 약속대로 나왔고, 일기 한 편은 약 64초(기록 Agent · 관측 Agent 각 30초 안팎 + 한마디)였다. 처리 중 keep-alive 가 5번씩 갔다.
- 사람 이름 2명은 글을 쓸 때 자동 등록돼 가명으로만 나갔고, 한마디에는 원래 이름으로 되돌아왔다. 다만 "시험 기간이랑"의 '기간'도 사람으로 자동 등록됐다(가명 처리 쪽 `NOT_NAMES` 에 없는 낱말, WS4 몫 — 밖으로는 가명이라 안전하지만 사람 목록에 섞인다).
- 둘째 글의 "예전에는 ~ 생각했는데, 오늘 ~ 알았다"는 해석(단정)으로 나왔고 `self_change`(스스로 쓴 변화)로는 안 잡혀 바뀜이 생기지 않았다(지난 글에 같은 믿음이 없어서 관계로는 맞음). 셋째 글의 "다시 지켰다"는 첫 글 다짐과 이어짐(점선)으로 이어졌고, 다짐은 열림 그대로다(사용자가 '지켰어요'를 누르면 닫힘).
- 모든 관계가 같은 해 안이라 영역을 넘는 선 · 사용자 확인 필요(`needs_confirm`)는 이번 글에서 나오지 않았다.
