## 무엇을 했나

- 입력: 가상 인물 하늘의 v7 결과(`data/demo/universe-haneul.json`, 글 29편 · 생각 61개 · 관계 43개)와, 하늘 보고서의 job_id 와 맞는 관측 Agent 1차 출력 25개(`runs/cache`, 읽기만).

- 관계 후보 107개(관측 Agent가 낸 그대로)를 v8 규칙(`app/service/rules`)으로 다시 걸렀다. 생각은 v8 칸으로 정리(clean_record)하고 상태 모델을 글 순서대로 밀었다(advance).

## 읽는 법

- 관계가 늘어난 주된 까닭: v7은 같은 두 **글** 사이 관계를 하나만 남기고 기간(7 · 14 · 30일)으로 버렸고, v8은 같은 두 **생각** 사이 하나만 남기고 기간 조건이 없다(2026-10-03 결정).
