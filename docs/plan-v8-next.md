## 5. 오케스트레이션 규칙

- **지난 세션 규칙 그대로:** 작업 묶음마다 에이전트 하나, `isolation: worktree`. 맡는 경로 밖은 고치지 않고 공통 파일은 오케스트레이터가 합친다. 병렬 에이전트는 `git stash` 금지(worktree 끼리 공유됨). 되돌림 확인은 `git diff > patch` → checkout → apply. 수용 기준은 테스트로 확인하고, 초록 실행만 믿지 말고 테스트 개수를 센다. 결정이 필요한 갈래만 멈추고 나머지는 계속, 대기 질문이 3개를 넘으면 묶어서 묻는다. 동규가 브라우저를 쓰는 동안 에이전트는 브라우저 도구를 쓰지 않는다.
- **배운 점(10/8):**
  - worktree 는 원격 기준으로 만들어질 수 있다. 에이전트는 먼저 `git checkout -b <브랜치> master` 로 로컬 master 에서 시작하고, `git log -1` 로 기준 커밋을 확인한다.
  - 하위 에이전트 프롬프트에 **동규 승인 원문**(무엇을 언제 허락했는지, 따옴표 그대로)을 넣는다. 넣지 않았더니 "승인을 못 봤다"며 멈춘 일이 있었다.
  - 비밀값은 vault `projects/talking-diary/_secrets/` 에만 둔다. 키 값은 읽거나 출력하지 않는다. Claude 는 웹 입력란(Vercel · Supabase · STT 콘솔)에 키를 넣지 않는다. 동규가 _secrets 파일에서 복사해 ⌘V 로 넣는다. 에이전트는 키 **이름**과 넣을 곳만 알려 준다.
  - 유료 호출(Studio · Solar · Upstage Parse · STT · TTS)은 실행마다 `runs/cost_ledger.jsonl` 에 적고, 갈래 끝에 합계를 보고한다. 누적 $50 을 넘기지 않는다.
  - 디스크 여유를 확인한다(10/8 기준 약 13GB). 갈래를 띄우기 전에 `df -h`, 합친 worktree 는 바로 지우고, 10GB 아래면 새 갈래를 띄우지 않는다.
- **이미 정해져 바꾸지 않는 것(10/8 동규, 하위 에이전트 프롬프트에 그대로 넣음):** 운영 상한 없음(env 손잡이는 비우면 무제한, 수익화 때 정함 — 새 기능도 사용 횟수 · 비용 상한을 기본으로 켜지 않는다. 파일 형식 · 크기 검사는 상한이 아니라 입력 검사라 둔다), 가입은 구글로 누구나(허용 목록 없음), 위기 대응은 시험 단계 방침(따로 뜨는 돌봄 화면 · 109 · 마들랜 안내 없이 평소 결과 + 위로 한마디 + 안부 한 줄, Solar 실패 때도 안부 한 줄, 감지는 암호문 기록 — 대화 · 사진 · 음성 · 가져오기 모든 새 길에 같은 판정을 건다), 가치 이름 · 빈 주제는 '기타 생각' 별, 비밀값은 vault `_secrets/`, 백엔드는 2차 가이드 모양(FastAPI + LangGraph · SSE · ChromaDB 하나 · `app/`).
- **2차 가이드 필수 산출물 유지:** 새 기능마다 `.env.example`(새 키 이름) · `docker-compose.yml` · `Dockerfile`(새 의존성) · `README.md`(실행 · 구조) · `docs/api-v8.md`(새 경로) 를 같이 고치고, 갈래 끝에 `docker compose build` 가 되는지 확인한다(GHCR 워크플로가 같은 이미지를 올림). 새 Agent(대화)는 LangGraph 그래프로 만든다(③).
- **운영을 깨지 않기:** 브랜치 → 테스트 · 골든셋 → 미리보기 배포에서 가상 인물로 확인 → master 합치기 → push(자동 배포) → 운영 `/health` 와 가상 글 한 편 확인. 마이그레이션은 덧붙이기만 하고, 운영 적용은 동규 승인 뒤. 문제가 생기면 Vercel 에서 이전 배포로 되돌린다(명령을 보고에 적어 둠).
- **동규만 하는 것:** 키 입력, 새 서비스 가입(STT 등), 운영 DB 마이그레이션 승인, Studio 설정 내보내기, 앱 공개 범위 변경, GitHub Variables, 영구 삭제.
- **시험 데이터:** 가상 인물(골든셋 인물)과, 현호가 동의한 글뿐. 사진 · 음성 시험 자료는 에이전트가 직접 만든 가상 자료로 한다.
